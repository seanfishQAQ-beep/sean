# WHITEOUT

First-person low-poly melee combat prototype in Godot 4.

## Run
Open this folder in Godot 4.3+ and press F6 or F5 to run the main scene.

## Controls
- WASD: move
- Mouse: look
- Left mouse: punch; hold to charge a heavy punch
- Z: switch between fists and detached arm
- Shift: sprint
- Space: jump
- E: finisher when close to stunned enemy, or interact
- Escape: release/capture mouse

## Prototype scope
A procedurally built sterile white hotel combat arena, black-suited faceless low-poly enemies, basic two-hit combat, charged knockback, detachable-arm mode, red impact particles, and a clear-floor elevator gate. This is a starting prototype, **not yet** the fully animated 5–8 minute demo. See TODO.md for missing acceptance criteria.
